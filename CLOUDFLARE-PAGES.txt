TECNOSHOP — PUBLICAR NO CLOUDFLARE PAGES

Este projeto está preparado para funcionar sem R2.

CONFIGURAÇÃO DO BUILD

Framework preset: React (Vite)
Build command: npm run build
Build output directory: dist
Root directory: /
Branch de produção: main

PUBLICAÇÃO PELO GITHUB

1. Envie para o GitHub o conteúdo desta pasta.
2. Entre no painel do Cloudflare.
3. Abra Workers & Pages.
4. Clique em Create application.
5. Escolha Pages e conecte seu repositório do GitHub.
6. Preencha os campos usando a configuração acima.
7. Clique em Save and Deploy.

O arquivo public/_redirects já está configurado para manter o React funcionando.

PUBLICAÇÃO DIRETA PELO TERMINAL

1. Execute: npm install
2. Execute: npm run build
3. Execute: npx wrangler pages deploy dist --project-name technoshopp

ARMAZENAMENTO SEM R2

- Produtos, usuários, pedidos e configurações ficam no localStorage.
- Imagens enviadas no painel ficam no IndexedDB do navegador.
- Nenhuma variável de ambiente, D1, Worker ou R2 é necessária nesta versão.

IMPORTANTE

Os dados cadastrados ficam apenas no navegador e no dispositivo utilizados.
Eles não são compartilhados automaticamente com outros visitantes.
