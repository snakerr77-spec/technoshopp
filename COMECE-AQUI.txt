TECNOSHOP — COMO ABRIR

1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra o terminal do VS Code.
4. Execute: npm install
5. Depois execute: npm run dev
6. Abra o endereço exibido no terminal.
